https://github.com/pbakaus/impeccable?ysclid=mv878exzjg465075435 - Набор навыков (skill) для дизайна интерфейсов. 24 команды вроде polish, audit, critique, animate и 59 правил-детекторов, которые ловят «AI-слоп» в вёрстке (фиолетовые градиенты, Inter везде, карточки в карточках).

https://github.com/DeusData/codebase-memory-mcp?ysclid=mv85jg9kv5741587461 -  Программа-«память» для кода. Индексирует проект в граф и позволяет агенту быстро искать связи, вызовы, зависимости.
Для чего тебе: Чтобы OpenCode не читал весь проект подряд, а делал точечные запросы. Экономит токены (в ~120 раз по их бенчмарку) и ускоряет анализ.
Как ставить: Через curl/PowerShell в терминале — она сама пропишется в конфиг OpenCode.

https://github.com/obra/superpowers - Методология разработки для агентов. Заставляет их работать по процессу: сначала брейншторм → план → TDD → ревью.
Для чего тебе: Чтобы агент не бросался сразу писать код, а сначала продумал улучшения. По сути — готовая «команда» с ролями (планировщик, исполнитель, ревьюер).
