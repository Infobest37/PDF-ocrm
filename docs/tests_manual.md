(graph.db и код проекта не менялись: только чтение и запуск `ask`; вывод фиксировался дословно)

## Легенда колонок
- Код — код возврата CLI: 0 = ответ выдан и все цитаты подтверждены на листах; 1 = отказ или есть неподтверждённые цитаты; 2 = ошибка окружения (не встретилось).
- Фрагментов — из строки вывода «Подтверждено N из M»: это цитаты блока «Доказательства». M всегда ≤ 3 (лимит max_claims); полное число найденных фрагментов текстовый вывод не показывает (для этого есть `--json`).
- «Ответ (кратко)» — суть выдачи по сниппетам + оценка релевантности: релевантно / частично / нерелевантно.

## Главное наблюдение прогона
Код 1 не получен ни разу на 20 вопросах: гейт min_score=0.35 всегда пропускает фрагменты, а цитаты машинно верифицируются. Поэтому код 0 = «цитаты настоящие», но НЕ = «ответ по теме»: на посторонние вопросы (16–20) и бытовые (7, 10, 15) выдаются нерелевантные, но дословно подтверждённые фрагменты со сканов. Выдуманных фактов нет (ответ — дословные выдержки).
