## Данные и индексация

- Абляционные негативы (скрытие эталонного листа пометкой `needs_rescan`) на этой документации непригодны: информация дублируется между изданиями и картами, после скрытия система отвечает с соседних листов, машинная проверка цитат проходит. 0 жёстких негативов из 28. - Прогресс индексации мерить числом записей (`SELECT COUNT(*) … pages_without_vectors`), не размером `graph.db`: WAL колеблется, размер врёт.

- Перезапуск `emb-index` безопасен: ветка continuation пропускает уже закодированное; повторный запуск идемпотентен.
- Чекпойнты Cline захватывают untracked-файлы в обход `.gitignore` и раздувают `.git` (было 647 МБ на бэкапах по 228 МБ). Держать чекпойнты выключенными, тяжёлые данные — вне папки репозитория.

## Поиск и отказ

- `min_score = 0.35` бессмыслен: лидер OR-ветки всегда 0.8, порог не сработает никогда. Отказ строится на гейтах по конкретике.
- Косинусы не разделяют корпусные и внекорпусные: 0.80–0.91 против до 0.817. Порог по близости невозможен, `MIN_COSINE = 0.18` ничего не отсекает.
- Гейты проверяют только лист-лидер. При смене порядка (например, после веса Ф1.5) защита исчезает — так потерян отказ на e04. Кандидат: проверять топ-3.
- Редкий термин (`rare_term`, df<1000) как гейт непригоден: задевает 17 из 23 корпусных.
- Вес specificity сравнивает конкретику по вхождению в текст: выдуманное число может случайно совпасть (400, 20 и т. п.), уточнение срывается в ответ. Clarify-полигон: было 10/10, стало 4/10.
- Мерж каналов был продублирован: `query.hybrid_search` и инлайн-блок в `answer.build_answer`. Правка одного места не меняет продакшн-путь (CLI, golden, GUI идут через `build_answer`).

## Код и контракты

- `_print_text` читает store (`is_continuation`): печать до `store.close()`, иначе `ProgrammingError: Cannot operate on a closed database` на ответе с парой соседних листов (исправлено в Ф1.3б.2, закреплено тестами).
- CLI-коды: `0` — ответ и все цитаты подтверждены, `1` — отказ или неподтверждено, `2` — ошибка среды, `3` — требуется уточнение (добавлен Ф1.4).

## Окружение Windows / PowerShell

- Кириллица в консоли отображается как cp866 — искажение отображения, не порча файла (файлы UTF-8).
- При копировании команд из Telegram в PowerShell к началу прилипает кириллическая «с» (получается `сcmd`) — команда не запускается; на таких строках PowerShell подвисает.
- `git show --output=` в PowerShell даёт пустой файл — захват вывода через Python subprocess; всегда `git --no-pager`.
- Долгие цепочки команд с `&&` в терминале Cline висят по 5 минут — выполнять по одной.
- Долговременная потеря сети к `max.km00.ru:8444` (прокси к модели) — это не ошибка проекта: правки в файлах целы, работа продолжается после восстановления.
