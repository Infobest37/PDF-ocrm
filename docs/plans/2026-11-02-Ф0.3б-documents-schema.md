## Правило наследования (карточка п. 3, `pdfgraph/documents.scope_allows`)

- `all` → документ применим ко всем бортам типа;
- `serials` → только к перечисленным в `applicability_serials`
  (запятая-разделитель, без дублей);
- `equipment` → к бортам с указанной опцией; список проставляет
  человек, до этого `scope_allows` возвращает False (fail-closed);
- пустая/отсутствующая строка → False.

## CLI (pdfgraph/cli.py, аудит в documents.log рядом с базой)

- `docs-list` — таблица всех полей по каждому документу;
- `docs-fill` — идемпотентное заполнение недостающих строк
  (существующие и ручные не перезаписываются);
- `docs-set --document --layer --serials --scope [--target --notes]` —
  правка, source=manual, status=ok, строка в documents.log;
- `docs-unset --document` — откат строки к авто-значениям, аудит в лог.
