## Контекст Д1а

- Карточка: Д1а — типы листов. Миграция аддитивная: `pages.page_kind`
  добавлена при открытии `Store` (схема 7→8), число строк `pages` не
  изменилось: 13 700 до и после. Запись `--write` выполнена: 13 700
  строк, пустых `page_kind` — 0.
- Классификатор: `pdfgraph/page_kind.py`. Перед маркерами отсекается
  колонтитул книги (тип ВС, «РУКОВОДСТВО...», «Стр. N», код раздела,
  «КАТАЛОГ...») в первых 400 символах; анализ идёт по следующим 400.
  Позиция маркера решает; «ТЕХНОЛОГИЧЕСКАЯ КАРТА» + «№»/«Наименование
  работы» рядом = бланк, ссылка без номера = упоминание.
- Содержательные типы: `purpose`, `techcard`, `faults`, `contents`,
  `table`, `list`, `scheme`, `title`, `catalog`; служебные статусы:
  `blank`, `service`, `other`.
- Штампы «Копия документа / Контрольная копия / Подлинник /
  Контрольная сумма / Распечатал / Дата печати» вырезаются до анализа:
  это служебная отметка, тип листа она не меняет. Если после вырезания
  текста не осталось — `service` (3 010 листов).
- `title` = 357 (<500): «УТВЕРЖДЕН», «УТВЕРЖДАЮ», «Лист регистрации
  изменений» (включая «временных»), «Титульный лист» в начале и слабый
  «Действительно для вертолетов» (только если после колонтитула нет
  содержательного текста).
- `faults` = 323: «ОТЫСКАНИЕ И УСТРАНЕНИЕ», «НЕИСПРАВНОСТЬ»,
  «ВОЗМОЖНАЯ ПРИЧИНА», «СПОСОБ УСТРАНЕНИЯ», «Каталог дефектов»,
  «ДЕФЕКТ», «ТРЕЩИН».
- `catalog` = 1 193: только по шапке — «КАТАЛОГ ДЕТАЛЕЙ...», все три
  слова шапки таблицы, «Рис. N» в начале строки + «поз.»; «СОДЕРЖАНИЕ»
  или «ВВЕДЕНИЕ» в первых двух строках после колонтитула побеждают
  `catalog`. Ложный каталог л.586 книги_1 двигателя — `other`.
- Контрольные листы: л.85 Д-1697 кн.2 — `faults`; л.49 Каталога

- `other` = 30.7% (ниже 35%) — условие записи выполнено, `--write`

- Решения владельца по Д1б (отказ «Описания назначения...», clarify для
