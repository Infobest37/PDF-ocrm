Дата: 2026-11-02T08:48:43+00:00. Источник: reports/applicability_audit.md (вне git), скрипт tools/applicability_audit.py (read-only на копии БД).

## Факты

- Документов: 49; по типам: «дополнение» — 19; «РЭ» — 10; «РТЭ» — 10; «каталог деталей» — 5; «каталог дефектов» — 2; «регламент ТО» — 2; «прочее» — 1.
- Применимость: в имени — 23, только в тексте — 0, не найдена — 26; по трактовке владельца none у слоя base означает «применим ко всем бортам типа», ручного решения требуют 2 документов (неоднозначный слой и дополнения без бортов).
- Дополнений (слой supplement): 19, у каждого борта перечислены прямо в имени («для вертолетов 22810 228811 24543»).
- Другие типы ВС по всему тексту: Ми-26 — 0 документов; Ка-32 — 1 документов; Ми-2 — 0 документов; Ми-17 — 4 документов.
- Формат бортовых номеров не однороден: кроме «2xxxxx» в штампах встречаются номера вне формата (№96555 в РЭ.РО Д-1263) — поле applicability_serials требует ручного подтверждения, автомат ловит только «2xxxxx» и «2X-XXX» (split с пробелом отсечён как ложный «стр. 20 207»).
