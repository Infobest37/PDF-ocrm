# Ф1.3а: полигон калибровки отказа — отчёт о выполнении

Завершена 2026-10-31. Продакшн-код не правился; только инструменты и отчёты.

## Что сделано

1. `tools/ablation_negatives.py` — абляционные негативы: якорь = середина
   эталонного листа (300 симв., дословно), ищется подстрокой по ВСЕМ листам
   копии graph.db; найденные листы скрываются механизмом `needs_rescan` /
   `rescan_reason = "auto: ablation Ф1.3а"` (пометка откатывается в `finally`
   строго после каждого вопроса), вопрос перезадаётся штатным
   `build_answer` + `verify_citations`. Отчёты в `reports/ablation_negatives.{json,md}`.
2. `tools/refusal_signals.py` — полигон классов: корпусные попадающие
   (hit@5), корпусные промахивающиеся, внекорпусные, абляционные,
   мутационные. Сигналы на листе-лидере: idf_coverage (формула BM25),
   редкий термин (df < 1000 — только записывается), доля чисел вопроса
   на лиде, совпадение типа ВС, совпадение ATA-группы, макс. косинус
   семантического канала. Замороженные 8 вопросов (seed 20261031,
   `reports/frozen_questions.json`) исключены из распределений.
   Отчёты в `reports/refusal_signals.{json,md}`.

## Наблюдения (факты, без порогов)

1. **Абляция не даёт жёстких негативов**: 0 из 28 — во всех случаях после
   скрытия эталонных листов система отвечала с подтверждёнными цитатами из
   соседних листов (28 ложных негативов). Семантический канал перекрывает
   лексическую дыру. Класс «абляционные» в полигоне пуст — недобор к
   требуемым 10.
2. **Ни одного отказа на всём полигоне**: 36/36 вопросов получили ответ,
   включая внекорпусные («погода в Твери») и мутации («Ту-154», несуществую-
   щий узел 400 с и т.п.). Отказ не срабатывает ни на одной входной форме.
3. Коридоры idf_coverage пересекаются (корпус 0.66 [0.36…1.00] против
   негативов 0.47 [0.13…0.67]); косинус различается на +0.02 медианы.
4. Разделение видно только у «доли чисел вопроса на лиде»: у корпуса-
   попадающих 1.00 (n=2), у мутаций и внекорпусных 0.00–0.67 (n=9).
   Выборка мала — кандидат для размышлений, не для решения.
5. `type_match` — всегда True (корпус однотипный); `ata_match` неприменим
   к негативам по построению (у них кода нет); `rare_term_on_leader` —
   True везде (df почти любого термина < 1000 при N≈12 тыс. листов).
   Эти три сигнала на данном полигоне не разделяют классы.
