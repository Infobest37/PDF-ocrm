# Отчёт: карточка Ф1.3б — гейты отказа по конкретике

Дата: 2026-10-31. Статус: выполнено, один коммит.

Задача: проверка конкретики вопроса (число, обозначение, тип ВС,
редкий термин) на листе-лидере вместо сигналов близости; сначала
замер на полигоне, включение только гейтов без задетых корпусных;
отказ — конъюнкция включённых с сообщением, какой гейт провален.

  По карточке «гейт, который рубит корпусные, не включаем вообще» —
  оба не включены.
- hit_at_5: **0.6429 (n=28)** — не изменился (база 0.643);

- Замороженные 8 вопросов прогнаны один раз, в самом конце (полный

- `.clinerules` (раздел 10) не обновлял: факты полигона Ф1.3б

## Риски

- Гейт `numbers` может отказать корпусному вопросу, значимое число
  которого отсутствует на листе-лидере (лидер — соседний лист без
  числа, ответ частично на нём). На текущем полигоне и золотом
  наборе таких нет (0.00 ложных), при пополнении набора —
  перезамерять.
- Типы ВС распознаются только написанием через дефис («Ми-8»,
  «Ту-154»); «Боинг 747» ловится числовым гейтом по числу, не типом.
- Гейты зависят от текста листа-лидера: отказ возможен и там, где
  ответ существует, но лидер его не содержит (частичный случай
  e04/e06) — цена условия «ноль ложных на включённых».
