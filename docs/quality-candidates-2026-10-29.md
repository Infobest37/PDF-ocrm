## Эвристика 29.10 (новые находки)

1. «почти пустой текст»: знаков < 24 → «низкое качество»;
2. битая кодировка: доля Latin-1-символов > 0.03 →
   «таблица без текста»;
3. «мусорные строки» (при ≥ 10 токенах): доля подряд
   повторяющихся токенов > 0.25, ИЛИ доля буквенных
   обрывков из 1–2 букв > 0.90, ИЛИ ни одного длинного
   (≥3 букв) буквенного слова;
4. таблица без текста: доля цифр > 0.88 при ≤ 3
   длинных буквенных словах;
5. «низкое качество»: знаков < 130.

Обрывки считаются только по буквенным токенам: числовые куски
кодов («078.00.5700» → «00») иначе заливают список каталогами.

## Режимы использования (для настройки 0.2)

- **Мусор-фильтр выдачи** — ядро: «мусорные строки» и «таблица
  без текста» (включая все строки источника «список 28.10»/«оба»)
  — ядро составлено так, чтобы ложные срабатывания на живых
  листах были близки к нулю.
- **Полный список** — для глазной проверки перескана; «низкое
  качество» — кандидаты, решение за человеком.
- **«нет ATA»** — признак дополнительный, с малым весом; решающие
  сигналы — содержание (латиница, каталожные строки) и качество
  текста (решение владельца, п. 3 задания 0.1г).
